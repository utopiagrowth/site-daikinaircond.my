# Utopia Starter Template
# DO NOT MODIFY THIS TEMPLATE DIRECTLY
# Clone this for new projects: cp -r ~/utopia-starter/ ~/[new-project]/

## What's Included
- Next.js 16 + Tailwind 4 + TypeScript
- Design system: clean white, .card class, animations
- Fonts: Bricolage Grotesque (headings) + Plus Jakarta Sans (body)
- Components: ScrollReveal, RotatingText, AnimatedCounter, FAQ accordion, testimonial carousel
- Layout: Navbar (always white), Footer (gray-50), MobileCTABar (sticky)
- Sections: Hero, SocialProof, FAQ, FinalCTA
- WhatsApp CTA pattern + fuchsia brand CTA

## To Customize
1. Change --color-brand in globals.css
2. Update constants.ts with real content
3. Replace placeholder text in sections
4. Add project-specific sections as needed
